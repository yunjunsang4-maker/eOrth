# 번체 중국어(zh-Hant, 대만식) 번역 어조 가이드·용어집

zh-Hant.ts를 쓰거나 고치기 전에 읽는다. 대상은 **대만·홍콩·마카오 사용자**이고 표기 기준은 대만이다.
현지인 검수에서 어조가 바뀌면 **이 문서를 먼저 고치고** zh-Hant.ts를 맞춘다.

## 1. 문체

| 자리 | 문체 | 예 |
|---|---|---|
| 버튼·탭·칩·메뉴 | 2~4자 동사구 또는 명사. 마침표 없음 | 下一步 · 儲存 · 關閉 · 去過的國家 |
| 안내문·설명·힌트 | 평서문, 문장 끝 「。」 | 位置資訊只用來填入居住國家，不會儲存。 |
| 질문형 확인창 제목 | 「要…嗎？」 전각 물음표 | 要回到登入畫面嗎？ |
| 오류·실패 | 「無法…」. 사과 안 붙임 | 無法確認目前位置。 |
| 접근성 라벨(a11y) | 짧은 동사구 | 上個月 · 清除搜尋 |
| 온보딩 슬라이드 제목 | 짧은 카피. 「，」로 호흡 끊기 | 旅程結束了，紀錄還在。 |

- **2인칭은 「你」**. 「您」은 은행·관공서 어감이라 소비자 앱에서 안 쓴다.
- 앱이 주어인 문장은 「我們會…」 또는 주어 생략. 한국어 「〜해드려요」의 생색 어감을 옮기지 않는다.
- 「請」는 사용자가 직접 조작해야 하는 안내에만(請選擇 · 請確認). 정보 전달 문장에는 안 붙인다.
- 「可以…」로 가능을 말하고, 「能夠」「得以」 같은 문어체는 피한다.

## 2. 표기 규칙 (대만 표준)

- **간체자 금지.** 대만 정자체만 쓴다. 자주 틀리는 것: 国→國, 设→設, 录→錄, 会→會, 数→數, 与→與, 从→從, 这→這, 个→個, 时→時.
- **대륙 어휘 금지, 대만 어휘로.** 软件/軟體, 数据/資料, 保存/儲存, 设置/設定, 相册/相簿, 登录/登入, 账号/帳號, 博客/部落格, 消息/訊息, 视频/影片, 网络/網路, 默认/預設, 搜索/搜尋, 点击/點一下, 信息/資訊, 支持/支援, 用户/使用者.
- 문장부호는 전각: 「，」「。」「？」「！」「：」「、」. 부호 앞뒤에 공백 없음.
- **한자와 영문·숫자 사이에 반각 공백 하나**(盤古之白): 「在 eOrth 使用」「4 到 30 個字」「{{count}} 天」.
  - 예외: 날짜 「{{y}}年{{m}}月{{d}}日」는 붙여 쓴다. 전각 괄호 「（）」 안팎도 공백 없음.
- 숫자는 반각. 양사: 次(횟수) · 天(일수) · 筆(기록 건수) · 個(일반) · 位(사람) · 張(사진).
- 박·일: 대만은 **일수가 앞** — `{{d}}天{{n}}夜`. 당일치기: 當天來回.
- 시간: 「上午 9:05」(上午/下午 앞, 반각 공백 하나). 요일 한 글자: 日一二三四五六.
- 줄임표 「…」 한 글자. 가운뎃점 「・」는 병렬에, 한국어 「·」 구분자는 그대로 유지(디자인 정렬).
- 영문 고유명사(eOrth, ID, STEP 1 / 2)는 그대로.

## 4. 하지 말 것

- 간체·대륙 어휘(2절 목록). 검수 전 눈으로 한 번 더.
- 「您」「請您」「親愛的使用者」.
- 「進行…」 명사화(進行儲存 → 儲存).
- 느낌표 남발. 「！」는 완료 축하 한 곳 정도.

## 5. 검수 순서

1. 이 문서 2·3절과 대조(간체·대륙 어휘가 가장 흔한 실수).
2. `npm test` — localeParity.verify.ts가 고아 키·한글 누출·**간체자 혼입**을 잡는다.
3. 현지인 검수는 온보딩→메인 샘플(zh-Hant.ts 1차분)로 먼저 받고, 이 문서에 반영한 뒤 나머지를 진행한다.
