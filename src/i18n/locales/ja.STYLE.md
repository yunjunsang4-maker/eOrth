# 일본어(ja) 번역 어조 가이드·용어집

ja.ts를 쓰거나 고치기 전에 읽는다. 목표는 "번역된 앱"이 아니라 "일본에서 만든 앱"처럼 읽히는 것.
현지인 검수에서 어조가 바뀌면 **이 문서를 먼저 고치고** ja.ts를 맞춘다 — 문서와 리소스가 어긋나면 다음 번역자가 옛 어조로 돌아간다.

## 1. 문체

| 자리 | 문체 | 예 |
|---|---|---|
| 버튼·탭·칩·메뉴 | 명사형 또는 체언 종지. 마침표 없음 | 次へ · 保存 · 閉じる · 訪れた国 |
| 안내문·설명·힌트 | です・ます체. 문장 끝 마침표 「。」 | 位置情報は居住国の入力にだけ使い、保存しません。 |
| 질문형 확인창 제목 | 「〜ますか？」 전각 물음표 | ログイン画面に戻りますか？ |
| 오류·실패 | 「〜できませんでした」. 사과(申し訳ありません) 안 붙임 | 現在地を確認できませんでした。 |
| 접근성 라벨(a11y) | 짧은 명사구·동사 연용형 | 前の月 · 検索語を消去 |
| 온보딩 슬라이드 제목 | 반말 종지(〜しよう · 〜になる). 광고 카피처럼 짧게 | 旅は終わっても、記録は残る。 |

- **앱이 주어인 문장은 「〜します」**로. 한국어 「〜해드려요」를 「〜してあげます」로 옮기지 않는다(생색내는 어감).
- **「〜してください」는 사용자가 직접 조작해야 하는 안내에만**. 정보 전달 문장에는 안 붙인다.
- 「〜しましょう」 남발 금지 — 유치원 안내문 어감. 온보딩 제목 정도에만.
- 경어 과잉 금지: 「〜くださいませ」「〜いただけますでしょうか」 안 씀.
- 한국어의 「〜예요/〜어요」(친근체)는 **です・ます**로 접는다. 일본어 앱은 친근함을 문체가 아니라 짧은 문장으로 낸다.

## 2. 표기 규칙

- 숫자는 반각. 조수사는 붙여 쓴다: `{{count}}回` · `{{count}}日` · `{{count}}件` · `{{count}}か国` · `{{count}}か所`.
  - 「ヶ国」「箇所」 대신 **「か国」「か所」**로 통일(현대 UI 표준).
- 날짜: `{{y}}年{{m}}月{{d}}日`. 요일 한 글자: 日月火水木金土. 시간: `午前 9:05`(午前/午後 앞, 반각 공백 하나).
- 박·일: `{{n}}泊{{d}}日`. 당일치기: 日帰り.
- 괄호는 전각 「（）」, 가운뎃점 「・」, 줄임표 「…」(한 글자). 한국어의 「·」 구분자는 ja에서 「·」 그대로 두되(디자인 정렬 유지) 문장 안 병렬은 「・」.
- 물음표·느낌표는 전각(？ ！). 마침표는 안내문에만 「。」.
- 말줄임 진행 표시: 「確認中…」.
- 영문 고유명사(eOrth, ID, STEP 1 / 2)는 그대로.
- 이모지는 ko/en과 같은 자리에 같은 것.

## 4. 하지 말 것

- ko 문장 구조를 그대로 옮기지 않는다. 한국어는 이유→결과, 일본어 UI는 결과부터.
- 「〜することができます」 → 「〜できます」.
- 「あなた」 남발 금지. 주어 생략이 자연스럽다. 강조가 필요한 온보딩 제목에만 「あなただけの」.
- 「※」 주의 표시, 「！」 남발 금지.
- 반각 카나(ｶﾀｶﾅ) 금지.
