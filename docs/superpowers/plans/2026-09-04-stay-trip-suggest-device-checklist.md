# 주변국 여행 카드 제안 — 실기기 체크리스트

전제: 개발 빌드 또는 베타 OTA. 사진 권한 '전체 허용', 위치 권한 허용. 진행 중 체류 카드 1건.

## 회귀 (Task 4 — 카드 생성 훅 추출)
- [ ] 프로필 → 과거여행 불러오기 → 결과 선택 → 저장: 카드 수·썸네일·완료 화면 수치가 이전과 같다
- [ ] 체류국 사진이 섞인 스캔: 체류 카드로 흡수(백데이팅), 제3국은 별도 카드
- [ ] 저장 후 여행 상세 → 사진첩 만들기: 풀 사진이 뜬다(saveTripPool 정상)

## 제안 (감지기·배너)
- [ ] 체류국에서 앱 실행 → 12시간 안에 두 번 열어도 스캔은 한 번(로그 `[StayTripSuggester]` 없음, 배터리 튐 없음)
- [ ] 최근 14일에 주변국 사진 5장 이상(마지막 사진 12시간 이상 경과) → 알림 1회 + 홈 헤더 아래 배너
- [ ] 알림 탭 → 홈으로 이동, 배너 보임
- [ ] [카드 만들기] → 카드 1건이면 여행 상세로 이동, 프로필 카드 목록에 썸네일 카드
- [ ] 같은 조건으로 앱 재시작 → 배너 다시 안 뜸(자산 id·기간 겹침 제외)
- [ ] **H1 재현 확인:** 배너가 뜬 상태에서 앱 강제 종료(스와이프) → 재실행 → **배너가 그대로 유지된다**
      (hydrate 전 빈 상태를 '체류 종료'로 오판해 pending을 지우던 결함. 지워지면 checkedAt 때문에
       최대 12시간 복구되지 않으므로 여기서 반드시 걸러야 한다)
- [ ] [나중에] → 사라짐, 24시간 뒤(기기 시각 조정) **앱을 백그라운드로 보냈다가 복귀**하면 재노출
      (now는 포그라운드 복귀·구독 갱신 때만 다시 판정한다 — 화면을 켜 둔 채로는 안 돌아온다)
- [ ] [×] → 사라짐, 재시작·재스캔에도 안 뜸
- [ ] 알림 설정에서 '주변국 여행 카드 제안' 끔 → 알림은 안 오고 배너는 뜬다
- [ ] 사진 권한 '선택한 사진만' → 아무 일도 없음(팝업 없음)
- [ ] 체류 종료 → 배너 사라짐
- [ ] 안드로이드: ACCESS_MEDIA_LOCATION 미승인 → 조용히 0건(팝업 없음)
- [ ] 알림을 한 번도 허용한 적 없는 계정: 발송 직전 **알림 권한 팝업이 뜬다**(위치·사진과 달리
      알림만 요청형이다 — 감지기 4종 공통 관례). 거부하면 배너만 뜨고 알림은 안 온다

## 배너 레이아웃 (홈 지구본 축소)
- [ ] 배너가 떠 있을 때 지구본/대륙 **토글·검색바·칩 위치가 깨지지 않는다**
      (`globeArea`는 flex:1이라 배너 높이만큼 지구본이 눌린다)
- [ ] 제안 **여러 건**(행 3~4개)일 때 배너 높이와 지구본 축소 정도가 견딜 만한가
- [ ] 안드로이드에서 우상단 **[×] Svg 버튼 터치**가 먹는다(RNSVG 터치 삼킴 함정 근처 — 여기서는
      Svg가 TouchableOpacity의 자식이라 정적으로는 해당 없음으로 판정, 실측만 남았다)
- [ ] 안드로이드에서 제안 행("🇨🇿 체코 여행 · 9.5 ~ 9.7 · 사진 37장")이 잘리지 않는다
      (`numberOfLines={1}`만 있고 `andFitText`는 붙이지 않았다 — 잘리면 그때 추가)
