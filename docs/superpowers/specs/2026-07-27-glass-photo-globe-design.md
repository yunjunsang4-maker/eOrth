# 유리 구슬 사진 지구본 재디자인 — 설계

## 목적

사진으로 활성화하는 지구본(form 2 · classic 변형)을 투명 유리 구슬로 재디자인한다.
시안 5장 기준: 미기록 상태는 연보라 유리 구슬(시안 1·2), 기록국은 대표사진이
유리 속에 박힌 조각처럼(시안 3·5), 배경 별밭은 기존 것 유지(시안 4).

- 미기록국: 연한 유리 양각 — 은은히 밝은 반투명 채움 + 하이라이트 윤곽 (사용자 확정)
- 유리 투명도: 상수 A/B 두 값을 실기기에서 비교 후 확정 (사용자 확정)
- 뒷면 대륙 비침: 넣는다 (사용자 확정)

## 접근 (채택: A. 텍스처+레이어 확장)

기존 캔버스 등장방형 텍스처 파이프라인을 유지한 채, 텍스처를 유리 톤으로 굽고
구 레이어를 겹친다. 셰이더 재작성(B)은 LOD 스왑·지역 창과 충돌 위험, 정적 PNG
오버레이(C)는 줌 시 구와 분리되어 탈락.

## 레이어 구성 (안→밖)

| # | 레이어 | 반지름 | 부모 | 역할 |
|---|---|---|---|---|
| ① | 뒷면 구 | 0.998 | globe | BackSide, 본체와 같은 텍스처, opacity ~0.12 — 유리 너머 뒷대륙 |
| ② | 본체 구 | 1.0 | globe | 기존 구. material transparent: true로 전환 |
| ③ | 반사 구 | 1.004 | **scene** | 회전 안 함 → 반사광 화면 고정. additive, 우상단 큰 소프트 반사 + 좌하단 보조 |
| ④ | 림 | 1.08 | globe | 기존 buildAtmosphere 재활용 — 흰-연보라 유리 테두리로 색·강도 조정 |

③을 scene에 직접 두는 것이 핵심: globe 회전과 무관하게 반사가 고정되고
(유리 구슬의 올바른 광학), 줌은 camera.zoom이라 자동으로 따라 커진다.

## 텍스처 규칙 (buildTexture)

| 요소 | 현행 | 재디자인 |
|---|---|---|
| 바다 | 불투명 남색 채움 | 반투명 연보라. 알파 = `GLASS_OCEAN_ALPHA` (A: 0.10 버블 / B: 0.35 반투명) |
| 미기록국 | 회색 채움 | 연보라 유리 양각: rgba(210,195,240,~0.22) 채움 + 위 밝은(흰 0.5)·아래 어두운 2줄 윤곽 |
| 기록국 | 사진 채움 + 흰 테두리 | 유지, 테두리 살짝 강화 |

- 캔버스는 fillRect 전에 clearRect — 알파가 살아야 material transparent가 의미 있다
- 바다 발광 블롭(oceanRadial)은 유리 톤에 맞춰 강도만 낮춰 유지
- photo 모드(8192 텍스처)에만 적용. flag·color 모드는 무변경

## 유지되는 것 (무변경)

국가 탭 판정 · 핀치 줌·LOD(110m/50m/10m) 스왑 · 지역 텍스처 창 · 국가명 라벨 ·
광고 마커 · 대표사진 커버 갱신 · aurora(색) 변형 전체 · 스킨 컨벤션(classic은
스킨 미적용 — 유리 톤 연보라 고정)

## 검증

- `npx tsc --noEmit` 0 (GlobeView.tsx는 HTML 문자열이라 타입 영향 최소)
- 실기기: 사진 0장(빈 유리) / 일부 기록 / 많은 기록 3상태 확인
- 회전·줌 중 반사광이 화면에 고정되는지, LOD 스왑 후에도 유리 톤 유지되는지
- 투명도 A/B 비교 후 상수 확정
