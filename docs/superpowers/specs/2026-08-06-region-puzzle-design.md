# 대륙(나라) 지도 퍼즐 활성화 — 설계

2026-08-06 · 대상: `CountryMapView`(나라 상세 지도)의 지역 활성화 표시

> **⚠️ 구현 후 변경 이력 (2026-08-07, 실기기 반응으로 확정)** — 아래 본문은 최초 설계이고,
> 다음 항목은 출시본 기준으로 달라졌다. 코드가 진실이다.
> - **렌더링**: 지역별 패턴 채움(A안) → **이미지 1장 + mask** (`ensurePuzzleLayers`).
>   패턴은 줌·팬 리페인트마다 지역 수만큼 다시 그려져 실기기에서 렉. clipPath가 아니라
>   mask인 이유는 월경지(경기 안 서울) — clipPath는 빼기가 안 된다.
> - **흑백 힌트 폐지**: 미방문 지역은 색 모드와 같은 빈 상태(#191920 실루엣 배경).
> - **기본 아트 폐지**: 퍼즐은 사용자 사진 전용. 사진 미선택 시 퍼즐이 그려지지 않고
>   시트에 안내(`main.puzzleNeedPhoto`)가 뜬다. `puzzleArt.ts`·생성 스크립트는 삭제됨.
> - **사진 선택은 즉시 확정**: 표시 설정의 취소(바깥 탭) 원복 대상에서 `puzzleImages` 제외
>   — 사진 고르기는 미리보기가 아니라 명시적 확정(원복하면 "적용 안 됨"으로 보였다).
> - **완성 판정은 RN(regionProgress)이 계산해 내려보낸다** (계획서 Self-Review 참고).
> - 줌 제스처 중에는 transform만 적용, stroke-width 보정은 제스처 끝(end)에서 1회.
>
> **2차 개선(2026-08-07 후속)** — 수정·보완·디자인 일괄:
> - **원본 보존**: `settingsStore.puzzleSources`(ISO3→크롭 전 원본 URI) 신규. 재조정은 항상
>   원본에서 시작(크롭의 크롭 화질 저하 방지), 앨범 원본은 확정 시 Documents/puzzle/에 영속.
>   교체·제거 시 참조 끊긴 사본은 파일까지 정리(누적 방지). remap·계정 전환 prune 동기화.
> - **완성 상태 강조 복구**: 경계선 숨김(stroke-opacity 0)을 피처별로 — 검색·인기명소
>   강조는 완성 나라에서도 보인다(`strokeOpFor`).
> - **연출**: 조각 채움 시 마스크 검정→흰 0.4초 페이드 + 가벼운 햅틱(`piecePlaced`),
>   완성 경계선 페이드 후 광택 스윕 1회(`playShineSweep`), 퍼즐 모드 탭 피드백은 채움
>   플래시 대신 스킨색 스트로크 펄스(그림 조각을 덮지 않게).
> - **빈 조각 재질**: 미방문 실루엣을 캔버스 그레인 타일 패턴으로(사진 힌트 아님 — 질감만).
> - **발견성·진행도**: 퍼즐 모드+사진 미선택이면 지도 위 "퍼즐 사진 고르기" 칩 → 표시 설정.
>   진행도는 유리 칩 + 스킨 그라데이션 프로그레스 바(애니메이션).
> - **완성 공유 카드**: 연출 2.6초 뒤 실루엣 마스크 카드(`PuzzleShareCard`) — iOS 공유 시트,
>   안드로이드는 갤러리 저장(RN Share가 안드로이드 이미지 첨부 미지원, expo-sharing은
>   네이티브 모듈이라 미도입).
> - **시트 미리보기**: 선택 그림을 나라 실루엣 ClipPath로 미리보기(`countryShape.ts` 공용
>   유틸 — 조정 오버레이·공유 카드와 같은 투영 수식).
> - 조정 오버레이: 실루엣 선 스킨색, 더블탭 리셋, 핀치 종료 시 배율 1.0 스냅+햅틱 틱.
> - 기타: 지오 없음 폴백 문구 i18n(`countryMap.noData`), photoCache 국가 전환 시 비움.

## 요약

나라마다 **그림 한 장**이 지도 전체에 깔리고, 지역(도/주) 하나가 퍼즐 한 조각이 된다.
방문한 지역만 그 조각이 선명하게 드러나고, 미방문 지역은 흐릿한 흑백 힌트로 보인다.
전 지역을 방문하면 경계선이 사라지며 온전한 그림 한 장이 완성된다.

지역 경계 자체가 조각 모양이다(지리 모양 그대로) — 요철 달린 직소 모양을 만들지 않는다.
퍼즐 감각은 "빈 조각(힌트) vs 채워진 조각(선명)"의 대비와 완성 순간이 만든다.

## 결정 사항 (사용자 확정)

| 질문 | 결정 |
|---|---|
| 퍼즐 단위 | 나라 지도의 지역(admin1) 단위. 지구본(나라 단위)은 범위 밖 |
| 그림 소스 | 기본 아트 1종(전 나라 공통) + 사용자 교체(그 나라 기록 사진 or 앨범) |
| 기존 모드와 관계 | 대륙 모드는 **지역별 사진 / 퍼즐** 둘만. 색 단독 모드 제거 |
| 빈 조각 | 흐릿한 흑백 힌트(`grayscale(1) brightness(0.3)`) |
| 완성 시 | 마지막 조각 글로우 + 햅틱 → 경계선 1초 페이드아웃 → 그림 한 장 |

## 렌더링 (A안: 공유 패턴 2벌)

`CountryMapView` WebView(SVG/D3) 내부에서:

```svg
<defs>
  <pattern id="pz-sharp" patternUnits="userSpaceOnUse" x=bx y=by width=bw height=bh>
    <image href="..."/>                                          <!-- 원본 -->
  </pattern>
  <pattern id="pz-hint" (동일 좌표)>
    <image href="..." style="filter:grayscale(1) brightness(0.3)"/>
  </pattern>
</defs>
```

- **`userSpaceOnUse`가 핵심**: 패턴 좌표가 지역이 아니라 지도 좌표계에 고정되므로,
  모든 지역이 같은 그림의 "자기 위치 조각"을 자동 샘플링한다. 조각 정렬 계산이 없다.
- 이미지는 나라 전체 bbox에 **cover-fit**(지구본 사진 핀의 cover 계산과 같은 방식).
  인셋(알래스카·하와이류 별도 박스)은 자기 박스 기준으로 따로 깔아 조각이 온전히 보이게 한다.
- `getFill()` 분기 추가: 퍼즐 모드에서 방문 지역 → `url(#pz-sharp)`, 미방문 → `url(#pz-hint)`.
  검색 강조·인기명소·탭 하이라이트는 기존 스트로크 로직 그대로(채움만 바뀜, 상호작용 불변).
- 지역별 사진 모드 코드는 그대로 두고 분기만 나뉜다.
- 폴백(B안): WebView에서 패턴 안 이미지 CSS 필터가 안 먹으면 RN에서 흑백 이미지를
  사전 생성해 두 장 주입. 실기기 검증에서 A안이 실패할 때만.

## 완성 판정과 연출

- 판정은 WebView가 자체 계산: `recordedRegions`에 매칭된 피처 수 == 전체 피처 수.
  RN 왕복 불필요. RN 쪽 `regionProgress`와 같은 기준이라 어긋나지 않는다.
- **전이 감지**: 데이터 갱신마다 재계산해 `미완성 → 완성` 전이에서만 연출한다.
  상태는 WebView 세션 변수 — 지도를 나갔다 오면 연출 없이 완성 상태로 렌더(남발 방지).
- 연출: ① 마지막 조각에 흰 글로우 펄스 0.5초 + RN에 `puzzleCompleted` 메시지(→ 햅틱)
  ② 전 지역 경계 스트로크 opacity → 0, 1초 ③ 완성 후에도 지역 탭 동작(히트 영역 유지).

## 데이터 모델

- `settingsStore.regionGlobalMode: 'photo' | 'puzzle'` — 기존 타입에서 `'color'` 제거.
- `settingsStore.puzzleImages: Record<string /*iso3*/, string /*uri*/>` — 신규.
  항목 없으면 기본 아트.
- 기본 아트: `assets/puzzle-art.jpg` 1장 — 앱 톤(다크 보라 네온)의 여행 콜라주/일러스트.
  신규 에셋 제작 필요.

### 기존 함정 회피 (필수)

- **iOS 컨테이너 경로**: `puzzleImages`의 URI는 재빌드 시 절대경로가 깨진다 —
  settings hydrate의 `remapDocumentUris` 대상에 반드시 포함한다.
- **WebView는 `ph://`를 못 읽는다** — 기존 `photoUriCache`(file:// 변환)를 재사용한다.

## 설정 UI (표시 설정 시트, 대륙 모드 섹션)

```
[ 지역별 사진 | 퍼즐 ]        ← 전역 토글 (색 제거)

퍼즐 선택 시:
  퍼즐 그림
  [기본 아트] [기록사진1] [기록사진2] … [+ 앨범]   ← 가로 스크롤, 현재 선택 테두리

지역별 사진 선택 시:
  기존 화면에서 지역별 세그먼트(기본/색/사진)와 색 팔레트만 제거,
  지역 목록·소급 태깅 진입점은 유지
```

- 그림 후보의 "그 나라 기록 사진"은 `recordedRegions` 수집과 같은 규칙으로
  그 나라 기록의 대표사진들을 모은다.
- 지역 데이터 미수록 국가(`totalRegionCount === 0`)는 퍼즐 모드 자체를 노출하지 않는다.

## 마이그레이션 (파괴 없이 무시)

- `regionGlobalMode === 'color'` → hydrate에서 `'photo'`로 치환.
- `regionDisplayModes`의 `'color'` 항목과 `regionColors`는 **삭제하지 않고 읽기만 중단**
  — 퍼즐이 실기기 반응에서 뒤집히면 되돌릴 길을 남긴다.
- 사진 없는 기록 지역의 폴백은 국가 기본색(`globeColor`) 하나로 단순화.
- `puzzleImages`는 신규 필드라 기존 사용자에 영향 없다.

## 검증 (`*.verify.ts`, npm test)

- 완성 판정 로직(피처 수 == 매칭 수), 경계값: 지역 데이터 미수록 국가.
- hydrate 마이그레이션: `'color'` → `'photo'` 치환, `puzzleImages` remap 통과.
- WebView JS 문법 검증에 CountryMapView 스크립트 블록 포함 확인(기존 check-globe-syntax 계열).
- 실기기 항목(자동화 불가, 문서화): 패턴 CSS 필터 렌더(iOS WK·안드 크롬), 인셋 cover,
  완성 연출 타이밍, ph→file 변환된 대형 사진 로드 시간.

## 범위 밖 (명시적 제외)

- 지구본(나라 단위) 퍼즐 — 이번에 안 건드린다.
- 퍼즐 미리보기 썸네일(설정 시트 안 나라 실루엣 미리보기).
- 완성 공유 카드 — 스크린샷 유도로 충분, 반응 보고 후속.
