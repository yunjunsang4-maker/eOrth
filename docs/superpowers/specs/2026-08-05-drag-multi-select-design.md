# 과거여행 불러오기 — 사진 드래그 다중선택 설계

작성일: 2026-08-05
대상 화면: `src/screens/ImportPhotoSelectScreen.tsx` (STEP N 사진 선택 그리드)

## 문제

사진 선택 그리드는 3열이고 한 여행에 수백 장이 들어온다. 지금은 **한 장씩 탭**하는 방법뿐이라
30장을 고르려면 30번 탭해야 한다. `전체 선택` 버튼이 있지만 "이 날짜 전부"라 중간을 골라내지 못한다.

## 결정 사항

사용자와 확정한 세 가지.

| 항목 | 결정 | 대안을 버린 이유 |
|---|---|---|
| 활성화 | **바로 드래그(가로 우선 판정)** | 롱프레스는 대기 시간이 생긴다 |
| 지나간 사진 처리 | **시작점 기준 범위 칠하기** | 셀마다 토글하면 손떨림에 값이 뒤집힌다 |
| 자동 스크롤 | **넣는다** | 없으면 한 화면(약 15장)까지만 고를 수 있다 |

상한 초과 처리는 구현자 판단: **드래그 중에는 조용히 멈추고(경고 진동 1회), 손을 뗀 뒤 안내를 한 번만** 띄운다.
장마다 Alert가 뜨면 기능을 쓸 수 없다.

## 구조

기하 계산만 순수 함수로 분리한다. 나머지는 화면 안에 둔다 — 선택 상태(`selected`)와 강하게
얽혀 있어 훅으로 빼면 인자만 8개가 되고, 재사용처도 없다.

### 신규 `src/utils/gridHitTest.ts` (순수 로직)

```ts
indexAtPoint(x, y, scrollY, geometry): number | null
rangeBetween(a, b): [start, end]
```

- 셀 크기·열 수·여백이 전부 상수라 좌표 → 인덱스가 계산으로 떨어진다
- 셀 사이 간격(gap) 위 좌표는 `null` — 호출부가 직전 인덱스를 유지한다
- 범위 밖·아이템 수 초과도 `null`
- 저장소 관례대로 **`gridHitTest.verify.ts`** 를 함께 만들어 `npm test`에 붙인다

### `ImportPhotoSelectScreen.tsx`

제스처, 선택 상태 갱신, 자동 스크롤 타이머.

```
GestureDetector(Pan)
  └ FlatList (numColumns=3)
```

`GestureDetector`는 뷰를 추가하지 않고 자식에 붙으므로 이벤트의 `x`/`y`가
**FlatList 로컬 좌표**로 온다. 별도 측정 없이 `indexAtPoint`에 그대로 넘길 수 있다.

## 인터랙션 규칙

| 상황 | 동작 |
|---|---|
| 가로 8px 이동 | 드래그 선택 활성화 (`activeOffsetX`) |
| 세로 12px 먼저 이동 | 제스처 실패 → FlatList 스크롤 (`failOffsetY`) |
| 시작 사진이 미선택 | `select` 모드 — 지나간 구간 전부 선택 |
| 시작 사진이 이미 선택됨 | `deselect` 모드 — 지나간 구간 전부 해제 |
| 손가락 되돌림 | 자동 복구 |

**되돌리기가 공짜인 이유**: 매 이동마다 "드래그 시작 시점의 선택 스냅샷"에서 다시 계산한다
(누적 토글이 아니다). 범위가 줄면 빠진 셀은 스냅샷 상태로 돌아간다.

**선택 순서**는 구간을 인덱스 오름차순으로 이어붙인다 → 뱃지 번호가 그리드 순서와 일치하고
앨범 사진 순서도 자연스럽게 정렬된다.

임계값(8px/12px)은 실기기 조정 대상이라 파일 상단 상수로 둔다.

## 자동 스크롤

- 리스트 위/아래 **80px** 안에 손가락이 들어오면 32ms 간격 타이머 시작
- 가장자리에 가까울수록 빠르게(최대 12px/틱)
- 매 틱마다 **현재 손가락 좌표로 인덱스를 다시 계산**해 선택을 확장한다
  (손가락이 멈춰 있어도 콘텐츠가 흐르므로 재계산이 없으면 선택이 따라오지 않는다)
- 손을 떼거나 제스처가 취소되면 타이머 정리

## 예외 처리

- **상한 도달**: 구간에서 앞쪽부터 남은 자리만큼만 담고 멈춤 + 경고 진동 1회.
  손 뗄 때 `imports.maxPhotosAlert`를 한 번만 표시
- **햅틱**: 새 셀에 진입할 때만 `selectionAsync()` (매 프레임 아님)
- **일별 필터**: 인덱스는 항상 `visiblePhotos` 기준. 필터가 바뀌면 드래그 상태 초기화
- **기존 탭**: 그대로. 제스처가 활성화되지 않으면 `PhotoCell`의 `onPress`가 동작한다
- **안내 문구**: 상단 부제에 "밀어서 여러 장 선택" 힌트 추가(한/영)
